# Logo placeholder

ใส่ไฟล์ `logo.jpg` (หรือ logo.png) ในโฟลเดอร์นี้ ขนาดแนะนำ:
- 240x240 px (square)
- < 50KB
- transparent background ถ้าใช้ png

ใช้ใน:
- ทุกหน้า LIFF (`<img class="logo" src="./img/logo.jpg" />`)
- LINE flex card header
- rich menu (script จะใช้เป็น watermark)

ถ้ายังไม่มี logo จริง ให้ใส่ภาพอะไรก็ได้ก่อน — แทนทีหลังได้
